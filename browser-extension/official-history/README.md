# 官方成交同步桥

1. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`。
2. 开启开发者模式 → 加载已解压的扩展程序 → 选择本目录 `browser-extension/official-history`。
3. 刷新工坊 → 交易追踪 →「同步官方成交」。已登录时直接读取；需要登录时会打开官网，正常登录后返回工坊自动继续。保持官方历史页打开。

**从旧版更新到 1.1.0**：在扩展管理页找到「PoE2 工坊 · 官方成交同步」，点击卡片上的重新加载按钮，再刷新工坊。无需删除扩展、重建账本或填写登录信息。新增的 `scripting` 权限仅用于给已经打开的官方历史页补装读取器，避免扩展显示已连接、官网页却没有读取脚本。

工坊会区分「同步桥已连接但尚未读取」「等待登录」「读取成功」和具体读取错误；桥已连接不表示账号成交已经同步。成功后立即更新交易记录和汇总，当前通货／时间／搜索筛选若隐藏了全部成交，会展示有账目币种的全部时间记录。不同通货仍分别统计。

只读取你在官网正常登录后可见的 `/api/trade2/history/{league}`；不读取 Cookie、口令、浏览器数据库或 PoB2 授权。权限仅限官方站点与本机 5173 端口，无外部服务。

该接口不是公开承诺覆盖范围的历史账本。目前已知资料以近期商人成交（卖出）为主，不能据此保证买入、密语成交或全部历史齐全。工坊展示这次实际读取的时间范围、方向和条数；本地按稳定交易标识去重，后续同步逐步积累。没有稳定标识时明确提示去重限制。官方返回错误时不生成交易。请在官网切换正确的账号与联盟后同步。

兼容官方成交的 ISO 日期、Unix 秒／毫秒时间戳；失效物品仍有来源标识、成交时间与金额时保留收支。无效条目逐项报告跳过原因，不将解析失败当作账户没有成交。代码和隔离浏览器测试完成，不代表已验证你账号的买入覆盖或历史长度。
