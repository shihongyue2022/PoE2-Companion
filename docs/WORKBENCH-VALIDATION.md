## 上游 Windows 测试兼容性修复

上游 Git 检出后的 CRLF 换行导致两处测试加载失败。工作流测试读取时统一换行为 LF；PoE2DB CLI 模块的测试导入在内存中规范换行并去除 shebang，避免 Vite 在 Windows 上将 shebang 放到导出包装之后。原制作算法、刷新生产模块和相关业务断言未改变。
