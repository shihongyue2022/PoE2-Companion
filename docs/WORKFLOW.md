# 日常操作通路

## 更新角色

游戏换装 → 工坊「角色装备」打开 PoB2 → Import/Export Build 勾选 **Delete equipment** → 重新导入天赋／珠宝及 Items and Skills → Ctrl+S → 工坊「保存后重新读取」→ 核对变化 → 确认替换。

工坊每 30 秒及回到窗口时检查当前来源文件的保存时间，只提示，不自动覆盖。网页读取的是 PoB2 存档，不直接读取游戏内存。护符或药剂取下后，预览应显示空栏；空栏会清除旧物品，物品库中未分配到 Slot 的物品不会自动穿上。如果预览仍显示护符，请检查 PoB2 当前角色、装备组、Delete equipment 和保存时间。

更新对照逐件显示同名装备的 roll、词缀、机制、状态与可读取的武器 DPS 变化；重复读取相同装备保留最近一次有变化的前后快照。此前已被覆盖的旧数据无法凭空恢复。

## 两套武器与角色面板

角色栏选择 I／II，仅该组主副手与共同装备参与汇总。展开「武器组 I / II · 装备贡献与面板依据」查看差异。装备汇总是固定数值贡献，不能当作最终游戏面板；本组没有角色总值基准时，不借用另一组总抗性或伤害。

官方更新记录明确涉及武器组技能限制、切组持续增益等机制，见 [GGG 0.2.0 更新说明](https://www.pathofexile.com/forum/view-thread/3740562)。工坊尚未完整重算专属天赋、精魂预留、持续增益、条件效果和技能最终伤害。要精确比较，需在 PoB2 分别切组重算保存，或在游戏中切组后校准。

## 查价与找升级

### 先选技能再选装备

在「智能配装」选择主要输出，再点「查看增伤词缀与部位」；也可以在「技能与构成」直接点技能或辅助宝石。查阅本身不改主输出或装备。详情先解释启用的辅助与特殊机制，再列出匹配的增伤词缀、可出现的部位、前后缀和 T3／T2／T1 档位；默认展开前 8 条，其他按方向筛选或展开。

旋风会特别提示同批命中间隔、地面／旋风联动；投射物加速 III 启用时，投速增加／减少才作为投射物伤害方向。手套的 Kolr’s Hunt 词池会明确显示解锁前提，不当作所有手套的普通词池。盛怒 II 的近战命中要求、齐射的封印节奏、元素武装 II 的适用伤害部分及莱基亚塔的流动的抗性反转分别说明，不把它们简单相乘。

选择词缀、部位和阶层 → 「检索这条词缀」（其他技能显示「以此为主输出并检索」）→ 工坊保存主输出选择，将词缀及档位带入现有装备检索 → 选择预算、查候选 → 比较整套。原装备尚未替换；传奇会按稀有替代检索，原传奇独有机制需核对。符文开放的词池条件随候选传回比较，避免在返回装备页时丢失投速联动的方向。

详情按原生英文技能、辅助和官方属性 ID 匹配，显示简体中文，并链接英文技能／辅助页、词池、GGG 更新说明和固定版本 PoB2 数据。资料可核对机制和词缀出现位置；当前没有完整 PoB 逐项增伤重算，因此展示的是匹配优先级，不能据此宣称某条是此 BD 的最大 DPS 提升。查看非保存主技能不会借用原技能的伤害快照。

### 按装备联合检索

1. 点选身上装备 → 「估价这件装备」或「寻找这件的升级」：统一进入紧凑的装备提升检索。选择预算档位；默认「整套规划」，四抗约束换装后的整套面板，不强制当前部位独自补齐。
2. 一行选择属性，后面的下拉菜单选择与当前相同或更高（0%）、只查相同，或 +1%／+3%／+5% 及以上。点「添加属性」增加联合条件，× 移除；只显示参与检索的属性，无需手填数值。
   「物品等级」可与词缀联合筛选，选择当前物等或常用最低物等档位，不参与核心属性降序。腰带另提供当前底座已核对的普通前后缀，包括生命、魔力、护甲、力量、四种抗性、生命回复，以及药剂／护符充能与恢复／持续时间方向；未拥有的属性标为「可新增」，使用 T3／T2／T1 起步及 T1 满 roll 档位，菜单标出所需物等。护符栏位可选 1／2／3。当前物品数值不因新增筛选而改变；未经核对的数值阶层不提供档位。传奇腰带默认仍查同名，主动切到「同类稀有腰带」才开放普通词池。
3. 点某行的 ↓ 设为降序优先属性。「核心属性降序」只用这一项排序，其他已选项仍是硬门槛，不能以一项更高抵消另一项下降。
4. 「检索提升候选」保留每项核心要求与预算，再按价格升序取最多 20 件。至少添加一项才能查询。调整预算或筛选时旧结果失效，选中的核心属性与百分比保留。
5. 返回物品逐件核对核心值，并显示换入后的整套四抗是否达标、各项缺口。默认保留可由其他部位补抗的候选，标为「需补抗 · 待组合」，不能当作已完成升级。选择「只换这一件」时，固定其他部位，才启用单栏抗性门槛并只保留整套已确认达标的物品；插槽联动在返回后核对，避免把每插槽加成误当作普通交易合计属性。未知基准不视为达标。
6. 候选点「比较这件」返回对应角色栏，核对整套四抗与技能机制，再确认替换。继续比较其他部位时累计计算换装差值；可跨部位补足缺口，目前不自动搜索多件组合。火冰雷与混沌分开；溢出抗性不增加伤害分。

普通装备查价集中于核心联合条件、预算、抗性约束和候选比较。底座／腐化／卖家筛选及未参与的机制按需展开，历史收藏放在结果下方。普通地图／材料继续按名称、等级、品质查价。核心属性门槛不代表已完成 PoB2 换装伤害重算。

搜索原生英文／官方 ID，展示映射为简体中文。查询失败和没有挂单分别提示；官方登录限制及限流不表示市场没有该物品。

## 官方成交与密语交易

「交易追踪 → 官方成交同步 → 打开扩展安装入口与目录」：首次在 Chrome／Edge 开发者模式加载项目 `browser-extension/official-history`。已安装旧版时在扩展管理页点击重新加载，更新到 1.1.0，然后刷新工坊。点击「同步官方成交」会直接读取；需要官网登录时返回工坊自动继续，不再停在只打开官网的步骤。可开启网页显示时每 2 分钟检查；不是后台常驻服务。

同步桥使用官方历史页自身会话请求 `/api/trade2/history/{league}`，不读取或保存 Cookie、口令、PoB2 授权。只转发允许的成交字段，按稳定来源标识、时间及方向去重并独立统计各币种。已完成的可读成交直接入账，未知通货进入待确认；无来源 ID 时使用内容指纹并提示其局限。

接口以近期商人卖出记录为主，公开文档不保证个人完整流水。每次同步展示实际最早／最晚时间、条数、卖出、显式买入及具体跳过原因。支持数字时间戳；物品详情失效但成交事实完整时保留金额。入账立即刷新收支，避免默认崇高石筛选隐藏神圣石成交。没有读到买入不等于没有支出；不保证固定天数或能补回全部历史。详见 [同步桥安装说明](../browser-extension/official-history/README.md)。截至本次交付，尚未用用户账号进行实际覆盖验证。

没有已确认支出时，卡片显示「未记录／待补支出」，不将仅有的卖出收入当作净利润；有部分支出时显示「已记录差额」。买入密语按报价预填金额和通货，一次确认实际成交后入账；方向标错可在交易列表直接切换买入／卖出，更正保留来源标识，重复同步不会覆盖或重复入账。完整游戏市集买入仍需核实可读的数据源，不能以更改标签宣称已接通。

密语报价从 Client.txt 单独读取，确认实际成交后才计入收支。密语、CSV、官方历史不同来源可能覆盖同一交易，跨来源重复仍需核对。交易收支与未售资产估值涨跌分开展示；这些记录仅保存在当前浏览器，建议定期导出账本备份。

## 验证

`npm.cmd run type-check`、`npm.cmd run build`、工坊 Vitest 回归，以及：

- `node scripts/workbench-integrated-flow-regression.mjs`：隔离样例验证护符移除、核心档位、候选回流、成交同步和持久去重、移动布局。
- `node scripts/workbench-official-history-extension-regression.mjs`：扩展来源校验、同源请求、字段白名单与限流。不会访问用户浏览器登录态。
